# welding-front

Фронтенд сварочного портала: Vue 3 + Quasar + Pinia + строгий TypeScript.
Данные ходят через сервисный слой (фасад → стор → компонент) на бэкенд по `/api/`.

---

## Запуск с нуля на новой машине

Нужен установленный Node.js (проверить: `node --version`) и Quasar CLI
(`npm i -g @quasar/cli`, если ещё не стоит).

### 1. Клонировать репу
```bash
git clone https://github.com/<логин>/welding-front.git
cd welding-front
```

### 2. Установить зависимости
```bash
npm install
```
(Ставит всё из `package.json` в локальную `node_modules/` — между машинами она НЕ переносится,
создаётся заново.)

### 3. Запустить дев-сервер
```bash
quasar dev
```
Откроется на http://localhost:9000 (порт может отличаться — смотри вывод в терминале).

---

## Важно: фронт работает В ПАРЕ с бэком

Приложение ходит за данными на `/api/...`. Чтобы данные пришли, ДОЛЖЕН быть запущен бэкенд.

Порядок запуска в разработке — **два терминала**:
1. Бэк (репа `welding-backend`): `python manage.py runserver` → поднимется на `:8000`
2. Фронт (эта репа): `quasar dev` → поднимется на `:9000`

Дев-сервер Quasar проксирует `/api` на бэкенд (`localhost:8000`) — настроено в `quasar.config.js`,
блок `devServer.proxy`. Поэтому в коде axios используется относительный `/api`, а не полный адрес.

> Прокси подхватывается только при СТАРТЕ дев-сервера.
> Поменяла `quasar.config.js` → перезапусти `quasar dev` (Ctrl+C и заново), иначе не применится.

## Как устроена связь с API

- Единый axios-клиент: `src/shared/services/http.ts` (`baseURL: '/api'` + перехватчик токена).
- Перехватчик сам прикладывает `Authorization: Token <ключ>` к каждому запросу,
  берёт токен из `localStorage`. В фасадах про токен думать не надо.
- Токен и user сохраняются в `localStorage` при логине → переживают перезагрузку (F5).
  `user` восстанавливается в стор при старте приложения (`restore()`).
- Фасады (`usersApi` и т.д.) — единственное место, где меняется «мок → реальный API».
  Сигнатуры методов и типы при этом не меняются, поэтому сторы и компоненты не трогаются.

## Работа на двух машинах

Между машинами ездит ТОЛЬКО код. НЕ переносится: `node_modules/`, `dist/`.

Ритуал:
- Сажусь работать → `git pull` → `npm install` (если менялся `package.json`)
- Закончила → `git add` → `git commit` → `git push`

## Частые грабли

- **CORS-ошибка в консоли** — прокси не подхватился (не перезапустила `quasar dev`)
  или запрос идёт мимо `/api`.
- **`401` на запросах** — нет токена (не залогинена) или токен протух → перелогиниться.
- **Данные не грузятся, в Network пусто/ошибка** — не запущен бэкенд на `:8000`.
- **`301` / редирект на запросе** — пропал слэш в конце пути (`/users/`, не `/users`).
- **Разлогинивает при F5** — не вызывается `restore()` при старте, или токен не в `localStorage`.
